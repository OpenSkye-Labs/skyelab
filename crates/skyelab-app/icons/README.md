# SkyeLab app icon

Edit `icon.svg` for the full launcher and `icon-small.svg` for desktop representations up to 32 physical pixels. Run `scripts/icons.sh` on macOS with resvg installed to regenerate the desktop and mobile assets. GPUI uses `peek.svg` on Welcome and `mark.svg` in compact placements. See the [brand guide](../../../docs/design/brand.md) for usage.
