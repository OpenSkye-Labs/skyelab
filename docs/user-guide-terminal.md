# The terminal drawer

Part of the [user guide](user-guide.md).

Opening the terminal drawer with no terminal open starts a shell. The drawer's tab bar has **Split right** (<kbd>⌘D</kbd>), **Split down** (<kbd>⇧⌘D</kbd>), **New terminal** (<kbd>⌥⌘T</kbd>) and **Close terminal** (<kbd>⌘W</kbd>, the active pane) buttons for the tab shown; a tab's **×** closes it. Right-clicking a terminal tab opens a menu with **Rename**, **Split right**, **Split down**, **New terminal**, **Close tab**, and **Close other tabs** (asking before closing busy shells when confirmation is enabled). Two unnamed tabs in the same folder are numbered (`project`, `project 2`). In a terminal, <kbd>⇧⌘D</kbd> splits down; elsewhere it opens Devices.
